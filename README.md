# makefun-ai-happy-01

[![make.fun · ai-happy-01](https://make.fun/c/ai-happy-01/badge)](https://make.fun/c/ai-happy-01)

Entry for [make.fun](https://make.fun) competition **ai-happy-01 — Make the AI judge happy**.

The program copies one image to `/output/entry.png`: a small friendly
robot watering a tall sunflower at golden sunrise — the image that makes
the AI judge happiest.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Image

A small robot watering a tall sunflower at sunrise, warm golden light,
dewy garden. Original illustration, generated for this entry.
